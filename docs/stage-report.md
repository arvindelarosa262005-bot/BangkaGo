The app is an initial working source implementation, not a certified or deployed public pilot. Operational requirements, production account configuration, automatic push/reminder delivery, provider failure/expiry reconciliation, comprehensive accessible native UI testing, and finance fee reconciliation remain release work. Admin data lists are currently bounded by the Data API row limit; move reports and search/pagination to server-side queries before operating at larger data volumes.

The subsequent [Realtime/UI update](realtime.md) adds the shared live controller, per-transaction signal migration, native network recovery, timed seat/fee refresh, notification inbox and refreshed maritime UI. Its executed results are recorded in [verification status](verification-status.md); hosted activation awaits the new project the user will create.
